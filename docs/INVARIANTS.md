# 数学不变量全景

> **每个算法至少一条可被独立实现交叉验证的硬标准。**
> 只要挂一条，就说明实现错了 —— 这是 `forge-ai` 的可证伪性所在。

判定符号：`rel` 为相对误差，`✅` 为 `verify.py` 中实测通过。

---

## 1. 数值线性代数（`forge_ai/linalg.py`）

| 算法 | 数学不变量 | 判定 |
| --- | --- | --- |
| Cholesky | `L·Lᵀ = A` | `max‖L Lᵀ − A‖ < 1e-8` ✅ `1.78e-15` |
| Jacobi 特征分解 | `Aυ = λυ` | `max‖Aυ − λυ‖ < 1e-8` ✅ |
| | 特征向量正交归一 `VᵀV = I` | `max‖VᵀV − I‖ < 1e-8` ✅ |
| SVD（单侧 Jacobi） | `U·diag(S)·Vᵀ = A` | `rel < 1e-6` ✅ `1.01e-15` |
| | 左正交 `UᵀU = I` | `< 1e-8` ✅ |
| | 奇异值与 `numpy.linalg.svd` 一致 | `< 1e-6` ✅ `1.78e-15` |
| QR 最小二乘 | 与 `numpy.linalg.lstsq` 同解 | `< 1e-8` ✅ `1.67e-16` |

**为什么 SVD 不用 `AᵀA` 特征分解？**
`AᵀA` 会把条件数平方（`κ(AᵀA) = κ(A)²`），6×6 随机矩阵重建误差退化到 `1e-7`。
单侧 Jacobi 直接对 A 的列做正交化，精度维持机器级。

## 2. 监督学习（`forge_ai/supervised.py`）

| 算法 | 数学不变量 | 判定 |
| --- | --- | --- |
| LinearRegression | 残差垂直于特征空间（正规方程）`Xᵀ(y − Xŵ) = 0` | `‖Xᵀr‖∞ < 1e-8` ✅ `5.98e-12` |
| | 闭式解与 sklearn 数值一致 | ✅ |
| LogisticRegression | `Σᵢ(pᵢ − yᵢ)xᵢ` 解析梯度 = 中心差分 | `maxRelErr < 1e-6` ✅ `6.98e-09` |
| SoftmaxRegression | 同上（多类） | 与 sklearn 标签一致 ✅ `0.917` |
| kNN | `k=1` 时训练集误差为 0（过拟合边界） | ✅ |

**梯度检验公式**（中心差分）：

```
∂L/∂θᵢ ≈ (L(θ + εeᵢ) − L(θ − εeᵢ)) / (2ε)
maxRelErr = maxᵢ |num − ana| / max(1e-8, |num| + |ana|)
```

> ⚠️ 必须在**未训练初值**处检验。训练收敛点梯度≈0，相对误差分母趋零会误报。

## 3. 无监督学习（`forge_ai/unsupervised.py`）

| 算法 | 数学不变量 | 判定 |
| --- | --- | --- |
| KMeans | 簇内平方和（inertia）随迭代单调不增 | ✅ |
| | 与 sklearn 聚类结构一致 | `ARI > 0.99` ✅ `1.000` |
| PCA | 主成分正交归一 `C·Cᵀ = I` | `< 1e-8` ✅ `8.88e-16` |
| | 解释方差与 sklearn 一致 | `rel < 1e-6` ✅ `5.26e-15` |
| | 秩-k 重建误差 = **Eckart–Young 下界** `Σ_{i>k} σᵢ²` | `rel < 1e-6` ✅ `2.65e-15`(JS) |
| GMM | 责任度每行和为 1 `Σₖ γᵢₖ = 1` | `< 1e-8` ✅ `9.99e-16` |
| | 混合权重和为 1 `Σₖ πₖ = 1` | ✅ |
| | 协方差对称且半正定 | 最小特征值 ≥ 0 ✅ `4.16e-17` |
| | **对数似然单调不减（EM 定理）** | ✅ |
| | 参数与 sklearn 一致（Hungarian 匹配） | `meanΔ=0.00 covΔ=0.00` ✅ |

**Eckart–Young 定理**：秩-k 截断 SVD 是所有秩-k 逼近中 Frobenius 误差最小的。
所以 PCA 的重建误差**必须**等于 `Σ_{i>k} σᵢ²` —— 这是一条能证伪的硬约束。

## 4. 深度学习（`forge_ai/deep.py`）

| 模块 | 数学不变量 | 判定 |
| --- | --- | --- |
| MLP | 反向传播梯度 = 中心差分 | `maxRelErr < 1e-6` ✅ `1.25e-08` |
| | 可过拟合训练集 | `acc > 0.9` ✅ `1.000` |
| 多头注意力 | 反向传播梯度 = 中心差分（含投影层 `Wq/Wk/Wv/Wo`） | `maxRelErr < 1e-6` ✅ `1.98e-07` |

**注意力反向推导**：

```
out = A·V,  A = softmax(QKᵀ/√d)
dV   = Aᵀ·dOut
dA   = dOut·Vᵀ
dS   = A ⊙ (dA − Σⱼ(dA ⊙ A))
dQ   = dS·K / √d
dK   = dSᵀ·Q / √d
```

softmax 的雅可比是 `A ⊙ (dA − Σ(dA ⊙ A))`，漏掉减项梯度必错。

## 5. 强化学习（`forge_ai/rl.py`）

| 算法 | 数学不变量 | 判定 |
| --- | --- | --- |
| QLearning | **Bellman 残差 → 0**：`max‖Q − (r + γ·max Q')‖` | `< 1e-2` ✅ `5.37e-04` |
| | 贪心策略 = 价值迭代最优策略 | `match = 1.000` ✅ |

> ⚠️ Bellman 残差**必须屏蔽终点态**。Q-learning 到达终点即终止，终点态 Q 恒为 0
> 且从不更新；把它算进残差会恒定得到 `1.0`（等于步长代价）。

## 6. 自洽三角

不变量之间互相咬合，形成闭环：

```
Cholesky ──▶ GMM 的 Σ⁻¹ 与 logdet ──▶ EM 对数似然单调
    │                                        │
Jacobi 特征 ──▶ PCA 主成分 ──▶ Eckart–Young 重建下界
    │
单侧 Jacobi SVD ──▶ SVD 重建 ──▶ 与 numpy 机器级一致
    │
梯度（MLP/Attention）──▶ 中心差分 ──▶ 解析梯度
    │
价值迭代（Bellman 不动点）──▶ Q-learning 残差 → 0
```

任一条断掉，整条链都会暴露它。这就是"可验证"的意义。
